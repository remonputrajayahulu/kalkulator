# kalkulator
Kalkulator-limit adalah aplikasi web berbasis Python dan Streamlit untuk menghitung limit fungsi matematika secara eksak dengan SymPy. Mendukung evaluasi limit dua arah maupun sepihak, langkah penyelesaian otomatis menggunakan Aturan L'Hôpital, serta visualisasi grafik kurva interaktif menggunakan Plotly untuk membantu pembelajaran kalkulus.
