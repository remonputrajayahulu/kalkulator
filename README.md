📔 Kalkulator-limit (Kalkulus-limit)🌠 Eksplorasi limit fungsi, Aturan L'Hôpital, dan kurva interaktif berbasis web.Kalkulator-limit adalah aplikasi web interaktif yang dibangun menggunakan Python dan Streamlit untuk mempermudah perhitungan serta visualisasi konsep limit dalam kalkulus. Aplikasi ini tidak hanya memberikan jawaban akhir secara eksak, tetapi juga menjabarkan langkah penyelesaiannya dan menampilkan grafik fungsi secara real-time.✨ Fitur Unggulan🎯 Kalkulasi Limit Eksak: Ditenagai oleh SymPy untuk menyelesaikan berbagai ekspresi aljabar maupun trigonometri, termasuk limit menuju tak hingga (oo / -oo).🧭 Kontrol Arah Pendekatan: Evaluasi limit secara fleksibel melalui Dua Arah (+-), Dari Kanan (+), atau Dari Kiri (-), lengkap dengan deteksi otomatis jika limit tidak ada (Does Not Exist / DNE).📝 Langkah Penyelesaian & Aturan L'Hôpital: Menampilkan proses perhitungan dalam format $\LaTeX$ yang rapi, termasuk deteksi otomatis bentuk tak tentu ($\frac{0}{0}$ atau $\frac{\infty}{\infty}$) dan iterasi penurunan Aturan L'Hôpital (hingga 3 iterasi).🎨 Grafik Kurva Interaktif: Visualisasi fungsi di sekitar titik limit menggunakan Plotly yang mendukung fitur zoom, pan, dan inspeksi koordinat saat kursor diarahkan ke kurva.💎 Desain Antarmuka Modern: Tampilan wide-layout yang bersih dengan gaya kartu modern, tipografi Quicksand, dan palet warna yang nyaman di mata.🛠️ Teknologi yang DigunakanPython 3.x — Bahasa pemrograman utama.Streamlit — Framework untuk membangun antarmuka web interaktif dengan cepat.SymPy — Mesin komputasi matematika simbolik dan turunan fungsi.Plotly — Pustaka pembuatan grafik interaktif.NumPy — Evaluasi array numerik untuk pemetaan kurva fungsi.📂 Struktur Proyekkalkulator-limit/
